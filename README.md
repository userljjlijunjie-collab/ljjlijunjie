# ljlijunjie - AI 驱动的 3D 国漫短剧制作工作流

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## 📖 项目简介

**ljlijunjie** 是一个专注于 **AI 辅助 3D 中国动画（国漫）短剧** 完整制作的工作流开源知识库。

**目前已辅助完成 4 个完整短剧项目**，系统整理了从 IP 分析、角色设计、剧情爆款策略、情绪推导、场景构建到最终交付的全流程文档，帮助创作者大幅降低 AI 内容生产门槛。

### ✨ 核心价值
- 提供可直接复制的实战工作流（v2.2 最新版）
- 结合最新 AI 工具（如图像生成、视频合成、剧情辅助等）
- 针对国漫风格的角色、道具、场景、连贯性优化指南
- **已成功辅助完成 4 个完整 3D 国漫短剧项目**，验证了工作流的实用性和有效性

## 📂 主要文档

- **AI-3D国漫短剧工作流-v2.2.md**：完整制作流程
- **走阴-IP视觉Bible-v2.2.md**：IP 分析与视觉圣经
- **走阴-STEP系列**：从 STEP1 到 STEP5 的分步实战
- **美术参考图提示词**：角色+道具+场景提示词库

## 🚀 如何使用

1. Clone 本仓库或直接浏览文档
2. 按照 STEP 顺序阅读并应用到你的 AI 工具链中
3. 根据提示词模板生成素材，组合成完整短剧
