## 五、补充说明

### 45° 动态图生成（四职业通用 prompt 前缀）

如果需要基于三视图生成 45° 动态参考图，在各角色三视图基础上使用以下前缀：

```
通用前缀：
Game CG quality Chinese fantasy 3D animation character design,
three-quarter view (45 degree angle), dynamic action-ready pose,
[角色描述插入此处],
professional character reference sheet style,
neutral grey background, highly detailed 3D render,
9:16 aspect ratio, full body visible with space for movement
```

### 使用顺序建议

1. 先用 Nano Banana 跑出技能态参考图
2. 将三视图（已有）+ 技能态（新生成）一起绑定给 Seedance
3. 开始执行 STEP 5 分镜落表
4. 如果技能态参考图不满意，调整 prompt 重新生成后再继续
